# 念诵记

这是一个无需帐号的个人念诵计数器。相同的“经典名称 + 日期”会自动累加；所有日期仍会保留为独立明细。

## 在 Mac 上使用

双击或用浏览器打开 `index.html` 即可。若要让离线安装功能正常工作，请从一个网站地址打开它。

## 在 iPhone / iPad 上安装

把此文件夹部署到任意静态网站服务后，用 Safari 打开网址，点“分享”→“添加到主屏幕”。它会以 App 形式启动。

## 三台设备的数据

当前版本的数据保留在每台设备本机，隐私最好。通过“导出备份”和“导入备份”可在设备间迁移记录。若希望三台自动同步，需要再接入 iCloud、Supabase 或 Firebase 一类的同步服务。
